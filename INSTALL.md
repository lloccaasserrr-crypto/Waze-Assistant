# 🔧 Пошаговая установка Waze Assistant

## Шаг 1: Проверь Python

Открой **PowerShell** или **CMD** и выполни:
```bash
python --version
```

Должна показать версию вроде: `Python 3.10.0`

Если ошибка - установи Python: https://www.python.org/downloads/windows/

## Шаг 2: Установи Ollama

1. Перейди на https://ollama.com/download
2. Нажми "Download for Windows"
3. Установи программу (как обычно)
4. Перезагрузи компьютер

## Шаг 3: Скачай модель

Открой **PowerShell** (как администратор) и выполни:
```bash
ollama run llama3.2
```

Подожди, пока загрузится. Консоль будет писать прогресс загрузки.

Когда увидишь:
```
>>> 
```

Это значит модель готова. Закрой окно (Ctrl+C).

## Шаг 4: Клонируй репозиторий

Выбери папку, где хочешь хранить проект, и выполни:
```bash
git clone https://github.com/lloccaasserrr-crypto/Waze-Assistant.git
cd Waze-Assistant
```

Если нет Git - установи: https://git-scm.com/download/win

## Шаг 5: Установи зависимости

```bash
pip install -r requirements.txt
```

Подожди, пока установятся библиотеки.

## Шаг 6: Запусти Waze

**Важно:** Сначала убедись, что Ollama запущена!

Открой **два окна PowerShell**:

### Окно 1 (Ollama):
```bash
ollama serve
```
Оставь это окно открытым.

### Окно 2 (Waze):
```bash
cd Waze-Assistant
python main.py
```

Готово! 🎉 Waze должен запуститься.

## ✅ Проверка

Если видишь:
```
==================================================
🤖 Waze запущен!
==================================================
```

Всё работает! 🚀

## ❌ Если что-то не работает

### Ошибка: "ModuleNotFoundError: No module named 'pyttsx3'"
```bash
pip install pyttsx3 SpeechRecognition pyaudio requests
```

### Ошибка: "Connection refused" или "Ollama не запущена"
```bash
ollama run llama3.2
```
Убедись, что это окно открыто в фоне.

### Ошибка: "Нет доступа к микрофону"
- Проверь настройки звука Windows
- Убедись, что микрофон включен
- Перезагрузи компьютер

### Ошибка при распознавании речи
- Требуется интернет для Google Speech API
- Включи WiFi/Ethernet

## 🎤 Первый тест голоса

1. Запусти Waze
2. Выбери режим: `голос`
3. Скажи: "Привет"
4. Waze должен услышать и ответить
